# Authoring boundary

## Bootstrap scope

This initial revision contains no adapted episode prose, route, character state, evidence model, or private production asset. `scenes/bootstrap.js` is a runtime smoke label rather than story content.

Before adding the first playable slice:

1. Re-read the current Notion slice contract.
2. Verify the current canon source revision and the exact manuscript material approved for adaptation.
3. Add only the scene-local state and public assets required by that slice.
4. Keep Aether-specific console/evidence mechanics project-local until cross-project duplication is demonstrated.
